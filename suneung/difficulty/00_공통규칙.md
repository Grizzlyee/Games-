# 난이도 공통 규칙 (모든 과목)

> 근거: `reports/학습 효과 최적 문제 난이도.md` 의 규칙집 R0~R9를 운영용으로 줄인 것. 규칙 번호는 보고서와 같다.
> 근거 등급: **[근거]** 연구로 직접 뒷받침 / **[부분근거]** 방향은 뒷받침, 숫자는 설계값 / **[외삽]** 연구에서 끌어낸 추정.
> 숫자 문턱은 대부분 설계값이다. 6~8주 기록 후 예측과 실제가 ±10%p 안에서 맞는지 확인하고 고친다 (R8-7).

## 핵심 원리 (한 줄 요약)
- **피드백이 붙는다는 전제에서 정답률 약 70~85%가 가장 효율적인 연습 구간**이다. 85% 규칙(Wilson 2019)은 기계학습 시뮬레이션 결과라 사람에게 그대로 검증되지 않았으므로 75~85% 띠로 쓴다. [부분근거]
- 처음과 슬럼프 때는 더 쉽게(85~90%), 실력이 오르면 조금씩 어렵게. 아주 어려운 문항(50% 미만)은 소량만, 반드시 해설과 함께. [부분근거]
- 정답 여부만 알려주는 피드백은 효과가 거의 없다(효과크기 0.05). **모든 오답에 설명 해설.** [근거]

## R0. 기록 항목 (문항마다)
문항 ID, 과목, 기능 태그, 형식(5지/단답), 수준(L1~L5, 0.5 단위), 칸(핵심/도전/복습/교차/예습), 정오, **확신(1 찍음·2 반신반의·3 확신)**, 소요 시간, 오류 코드(R6).

피드백 (R0-2, [근거]): 오답과 확신 1인 정답에 ① 정답 ② 단계별 이유 ③ 고른 선지가 틀린 이유 ④ 관련 기능 표시.

특수 규칙
- **R1-1** 피드백 없이 보는 시험은 75% 넘게 쉽게 짠다. [부분근거]
- **R1-2** 예습 도전(아직 안 배운 개념, 50% 미만 예상)은 시험당 0~2문항, 점수에서 빼고 바로 전체 풀이 공개. 선수 개념이 없으면 내지 않는다. [부분근거]
- **R1-3 슬럼프 복귀**: 2주 연속 하향, 낙담 표현, 공부 건너뜀 → 1~2주 A-초기 띠(85~90%)로. [외삽]
- **R1-4** 어떤 칸이든 3주 연속 95% 이상 → 이미 아는 것. 수준을 올리거나 복습 간격을 늘린다. [부분근거]

구성 규칙
- **R3-1** 지난 범위(간격 복습 + 교차) **40% 이상**. [부분근거]
- **R3-2** 교차는 헷갈리는 유형끼리 (수열 vs 급수 상황, 극값 vs 넓이, 빈칸 vs 순서·삽입 등). 습득한 유형이 2개 미만이면 교차 칸을 간격 복습으로 대체. [부분근거]
- **R3-3** 어휘·목록 암기는 섞지 않고 간격 반복으로. [부분근거]
- **R3-4** 가장 약한 과목은 간격 복습 +10%p, 핵심 −10%p. [외삽]
- **R3-5** 과목당 집중 기능 3~5개. 우선순위: 시험 비중 큼 → 아직 미숙달 → 선수 기능은 숙달. 측정 중인 기능에 3문항 이상. [외삽]
- **R3-6** 문항별 예측 정답률 평균(ΣP/N)이 단계 목표 ±3%p 안에 들 때까지 문항 교체. [외삽]
- **R3-7** 맞춤 시험은 쉬운 → 어려운 순서. 실전 모의는 실제 번호 순서. [부분근거]
- **R3-8** 교차 칸은 시간이 20~30% 더 든다고 보고 시간을 잡는다. [외삽]

## R4. 난이도 상향·하향
### R4-1 과목 다이얼 (매주 필수, 계단법) — 과목 수준을 ±0.5 이동
| 단계 | 목표 | 상향 (+0.5) | 유지 | 하향 (−0.5) |
|---|---|---|---|---|
| A-초기 | 85~90% | 2주 연속 95% 초과 | 80~95% | 1주라도 80% 미만 |
| A | 80~85% | 2주 연속 90% 초과 | 75~90% | 1주라도 75% 미만 |
| B | 75~80% | 2주 연속 85% 초과 | 70~85% | 1주라도 70% 미만 |
| C 맞춤 주 | 72~78% | 2주 연속 85% 초과 | 65~85% | 1주라도 65% 미만 |
| D | 실전 고정 | — | — | 오답 재시험 세트만 85~90% 유지 |

세칙: 20문항 미만 과목은 2주 합산. 실전 모의 점수는 다이얼에 안 넣음(오답은 사다리에 넣음). 하한 미달 원인이 교차 칸(60% 미만)뿐이면 다이얼은 그대로, 해당 유형을 1~2주 묶음 연습으로.

### R4-2 기능별 θ 갱신 (선택, 정밀형) [외삽]
- 초기값: 진단에서 5지 60%·단답 50%가 나오는 수준. 진단이 없으면 θ=2. 안 배운 기능은 '미학습'.
- 점수 x: 정답 1, 오답 0. **확신 1인 정답, 실수(S), 시간(T) 오답은 0.5**.
- 갱신: 기능별로 n(문항 수), O=Σx, E=ΣP(예측 정답률 합) → **θ_new = θ + K·(O − E)/n**
- K: 누적 15회 미만 2.0, 이후 1.0. 주당 변화 ±1.0 이내. 누적 10회 미만인 θ는 참고용.

### R4-3 하향·도움 복귀 (하나라도 해당하면)
| 조건 | 조치 |
|---|---|
| 최근 5~10문항 정답률 50~60% 미만 | 그 기능 L−1, 핵심 칸 2~3문항 |
| 해설을 본 뒤에도 같은 기능 2연속 오답 | 도움 한 단계 복귀 (독립 문제 → 부분 예제 → 완전 예제) |
| 노력 7/9 이상인데 정답률 60% 미만 | 도움 한 단계 복귀 |
| 개념 오류(K) 확인 | 선수 기능으로 돌아가 예제 → 부분 예제 → 문제 |

### R4-4 상향·건너뛰기
| 조건 | 조치 |
|---|---|
| 숙달 기준(R5) 충족 | L+1, 그 수준은 복습 순환으로 |
| 교차·지연 세트에서 2회 연속 85~90% 이상 | L+1 |
| 첫 단계 진단 3문항 중 2개 이상 정답 | 예제 생략. 짧은 점검 4/5 이상이면 잠정 숙달 |

### R4-5 하향하지 않는 경우
교차 칸 60~80% / 숙달한 기능의 단발 실수(S) (2주 안에 같은 수준 2회 틀리면 하향) / 같은 날 점수 / 실전 모의 점수.

## R5. 숙달 기준 (힌트 없이 처음 시도한 결과로만)
- **R5-1 기능 숙달**: ① 2주 이상에 걸친 최근 8~10회 정답률 80% 이상 **그리고** ② 마지막 3회 연속 정답(확신 2~3). [부분근거·외삽]
- **R5-2 기초 선수 기능** (다항식 연산, 지수·로그 법칙, 국어 문법 기본, 영어 기본 구문 등): 4~5연속 정답.
- **R5-3 단원 숙달**: 처음 보는 수능형 10~20문항 혼합 점검 80% 이상 + 60% 미만 기능 없음 + 1~7일 뒤 5문항 지연 재확인 80% 이상.
- **R5-4 미달**: 교정 후 평행 재시험. 2회 떨어지면 잠정 진급 + 간격 복습 예약 (진도 보호).
- **R5-5 오답 문항 졸업**: 서로 다른 날, 해설 없이 2~3회 연속 간격 재풀이 성공.
- **R5-6 암기 카드**: 첫 세션 3회 정답 회상 → 3회 이상 간격 재학습.
- **R5-7**: 숙달 판정 기능이 1주 뒤 점검에서 80% 미만이면 기준을 올린다.
- 이유(🔢): '8회 안에 3연속'만 쓰면 정답 확률 0.5인 학습자도 42% 통과. '10개 중 8개 이상'을 더하면 0.5는 5.5%, 0.9는 93% 통과.

## R6. 오답 코드
판정 순서: ① 확신 확인 → ② "k단계가 틀렸다" 힌트만 주고 다시 풀게 함 (고치면 S) → ③ 같은 유형 다른 문항에서도 같은 단계 오류면 P → ④ 겉모양 바꾼 문항도 틀리거나 이유 설명 못 하면 K → ⑤ 다시 읽고 바로 맞히면 R → ⑥ 시간 부족이면 T.

| 코드 | 유형 | 즉시 조치 | θ 점수 | 다음 시험 반영 |
|---|---|---|---|---|
| K | 개념 오류·선수 결손 | 선수 기능으로 돌아가 완전 예제 → 부분 예제 → 문제 | 0 | 해당 기능 L−1, 선수 기능 핵심 칸 2~3문항 |
| P | 절차 오류 | 내 풀이와 올바른 풀이 나란히 비교 + 연습 2~3문항 | 0 | 같은 기능 핵심 칸 2~3문항, 1주간 교차 제외 |
| S | 실수 | 검산 습관 점검 | 0.5 | 사다리에만. 10문항 중 2회 이상이면 P로 재분류 |
| R | 독해·해석 오류 | 발문·선지·자료 읽는 과정 피드백, 국어는 배경지식 보충 | 0 | 같은 지문 유형 1세트 |
| T | 시간·전략 오류 | 시간 배분 점검 | 0.5 | 난이도 그대로, 시간 조건만 강화 |
| G | 찍어서 맞힘 (확신 1) | 오답과 똑같이 해설 학습 | 0.5 | 사다리에 넣음, 숙달 연속 정답에서 제외 |
