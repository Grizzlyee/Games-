# 수학 난이도 기준과 현재 상태

> 공통 규칙은 `00_공통규칙.md`. 이 파일은 수학 전용 척도와 **학습자의 현재 수학 상태**를 담는다. 채점할 때마다 4~6절을 갱신한다.
> 마지막 갱신: 2026-11-03 (4차 채점 반영)

## 1. 실제 시험 (2028학년도)
- 30문항 · 100분 · 100점, 범위: **대수, 미적분Ⅰ, 확률과 통계** (공통, 선택과목 없음). 미적분Ⅱ·기하 제외. 공통수학1·2는 간접 출제 범위.
- 2025-04-15 예시문항 배치 (⚠ 실제 시험 배치는 2027-03 시행기본계획에서 확인 필요)

| 번호 | 형식 | 배점 |
|---|---|---|
| 1~3 | 5지선다 | 2점 |
| 4~13 | 5지선다 | 3점 |
| 14~21 | 5지선다 | 4점 |
| 22~25 | 단답형 | 3점 |
| 26~30 | 단답형 | 4점 |

- 평가원은 문항별 정답률을 공개하지 않는다. 정답률은 EBSi·업체 추정치만 있다 (⚠추정).

## 3. 수학 L1~L5 척도 (R2-2)
| 수준 | 요소·단계 | 유형 단서 | 표상·낯섦 | 형식 | 도움 (비계) |
|---|---|---|---|---|---|
| L1 | 개념 1개, 1~2단계 | 한 유형씩 묶음, 예제 직후 | 기호만, 정형 | 2점형 | 바로 스스로 풀기 |
| L2 | 개념 1개, 3~4단계 | 묶음, 부분 예제 | 겉모양만 변형 | 3점형 | 예제 1개 → 문제 |
| L3 | 단원 안 개념 2개 (요소 5~7) | **섞음, 유형 표시 없음** | 그래프·표·문장을 식으로 1회 전환 | 3~4점 | 예제 → 부분 예제 → 문제 |
| L4 | 단원 간 결합, 5단계 이상 또는 경우 나누기 | 섞음 | (가)(나) 조건 해석, 그래프 추론 | 다개념 4점 | 구성 기능을 모두 L3에서 숙달한 뒤 |
| L5 | 새로운 결합 | 실전 혼합 | 낯선 틀 | 후반 4점 (⚠추정) | C단계 이후 시험당 1~2문항 |

운영 규칙
- 기능 하나를 숙달하면 그 기능은 요소 1개로 다시 센다 (어제의 L3가 오늘의 L2). [부분근거]
- 단답형은 같은 수준이라도 예측 정답률을 단답형 줄로 계산한다 (찍기 하한 없음).
- 새로 배우는 복잡한 주제는 L1 예제부터 (완전 예제 → 부분 예제 → 문제). [부분근거]
- 교차 짝 예시: 순열 vs 조합, (g∘f) vs (f∘g), 꼭짓점 vs 최댓값·최솟값, 판별식 >0 vs ≥0, 나머지정리 vs 인수정리.
- 풀이 습관 지도: 식 표기(등호 오용), 조건을 다 썼는지 확인, 단답형 답이 자연수로 나오는지 검산.
