# 통합사회 난이도 기준과 현재 상태

> 공통 규칙은 `00_공통규칙.md`. 채점할 때마다 4~5절을 갱신한다.
> 마지막 갱신: 2026-11-03

## 1. 실제 시험 (2028학년도)
- 25문항 · 40분 · 문항당 1.5 / 2 / 2.5점 (2.5점은 다단계 추론이나 자료 2개 이상)
- 문·이과 모두 통합사회와 통합과학 **둘 다** 응시. 과목별로 성적 산출
- 배점별 문항 수 분포는 아직 확인 못 함 (⚠ 2027-03 시행기본계획). 예시문항은 2024-09, 2025-04-15 공개 → L4~L5 기준점

## 2. L1~L5 척도 (R2-4, 블룸 개정 분류 기반) [부분근거]
| 수준 | 블룸 수준 | 통합사회 문항 예 | 배점 대응 |
|---|---|---|---|
| L1 | 기억 (사실) | 용어·개념 회상 | 1.5점 |
| L2 | 이해 (개념) | 분류·비교·설명, 그럴듯한 오답 선지 | 1.5~2점 |
| L3 | 적용 | 경제·법·지리 원리를 새 사례에 적용 | 2점 |
| L4 | 분석 (자료 1개) | 통계·지도·제시문 해석 | 2~2.5점 |
| L5 | 분석·평가 (단원 융합, 자료 2개 이상) | 영역 융합 + 복수 자료 | 2.5점 |

## 3. 운영 규칙 [외삽]
- **A단계부터 자료 해석(L3~4) 문항을 20% 이상** 섞는다. 사실 문항만 풀면 고차 문항 실력이 오르지 않는다 (Agarwal 2019). [부분근거]
- 개념도는 기억으로 먼저 그린 뒤 확인하는 인출 연습으로만 쓴다 (Karpicke & Blunt 2011). [부분근거]
- 용어·개념은 간격 반복 카드로 (R7-4).
- 휴무일 화요일 3시간 배정 (학습자 시간표).

- 15문항, 약 25분: 중학 사회 기초 L1 5문항 + 통합사회 개념 L1~L2 6문항 + 자료 해석 L3 4문항
- 기록: 영역(사회·경제·법·지리·윤리)별 정답률, 오류 코드
