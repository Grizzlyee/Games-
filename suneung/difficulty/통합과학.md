# 통합과학 난이도 기준과 현재 상태

> 공통 규칙은 `00_공통규칙.md`. 채점할 때마다 4~5절을 갱신한다.
> 마지막 갱신: 2026-11-03

## 1. 실제 시험 (2028학년도)
- 25문항 · 40분 · 문항당 1.5 / 2 / 2.5점 (2.5점은 다단계 추론이나 자료 2개 이상)
- 문·이과 모두 응시. 이과라도 물리·화학 등 과탐 선택은 없음
- 배점별 문항 수 분포는 아직 확인 못 함 (⚠ 2027-03 시행기본계획). 예시문항(2024-09, 2025-04-15)이 L4~L5 기준점

## 2. L1~L5 척도 (R2-5, 블룸 개정 분류 기반) [부분근거]
| 수준 | 블룸 수준 | 통합과학 문항 예 | 배점 대응 |
|---|---|---|---|
| L1 | 기억 (사실) | 용어·법칙 이름 회상 | 1.5점 |
| L2 | 이해 (개념) | 개념 분류·비교 | 1.5~2점 |
| L3 | 적용 | 원리로 실험·반응 결과 예측 | 2점 |
| L4 | 분석 (자료 1개) | 그래프·표·실험 결과 해석, 변인 찾기 | 2~2.5점 |
| L5 | 분석·평가 (단원 융합, 자료 2개 이상) | 영역 융합 (예: 화학+지구과학) + 복수 자료·계산 | 2.5점 |

## 3. 운영 규칙 [외삽]
- **A단계부터 자료 해석(L3~4) 문항 20% 이상** (Agarwal 2019; McDaniel 2011·2013 과학 퀴즈 연구). [부분근거]
- 계산이 들어가는 문항은 수학 기능(비례식, 단위 변환)과 연결해 오류 코드를 K(과학 개념)와 P(계산 절차)로 구분.
- 개념도는 인출 연습으로만, 용어·법칙은 간격 반복 카드로.
- 휴무일 월요일 3시간 배정 (학습자 시간표).

### 진단 시험 계획
- 15문항, 약 25분: 중학 과학 기초 L1 5문항 + 통합과학 개념 L1~L2 6문항 + 그래프·표 해석 L3 4문항
- 기록: 영역(물질·생명·에너지·지구)별 정답률, 오류 코드
