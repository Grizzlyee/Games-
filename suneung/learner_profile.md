- 직업: 빵집 근무, **수~일 근무 / 월·화 휴무**, 출근은 15분 전에 나가면 됨

- 하루 수학 3시간 가능하다고 처음에 답함 → 전 과목으로 확장해 아래처럼 배분

|---|---|---|
| 오전 근무일 | 약 3시간 45분 | 07:00 수학 1h / 18:15 국어 1h / 19:15 영어 1h / 20:15 수학 오답 45m |
| 오후 근무일 | 약 4시간 15분 | 08:30 수학 2h / 10:30 국어 1h / 11:30 영어 45m / 22:00 영어 단어·한국사 30m |
| 휴무일 (월·화) | 약 10시간 | 수학 3h / 통합과학(월)·통합사회(화) 3h / 국어 2h / 영어 1h / 주간 오답 1h |
