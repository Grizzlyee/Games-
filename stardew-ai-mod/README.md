# 스타듀밸리 AI 대화 모드 (Stardew AI Expanded V2) 자동 설치

윈도우 PC 전용. 스타듀밸리(Steam 또는 GOG)가 설치되어 있어야 한다.

## 실행

1. 이 폴더의 `install.bat`, `install.ps1` 두 파일을 PC의 같은 폴더에 받는다.
2. 게임을 끄고 `install.bat`을 더블클릭한다.
3. 모델 번호를 고르고 오픈라우터 키(`sk-or-...`)를 붙여넣는다.
4. 바탕화면의 `Stardew Valley (SMAPI)`로 게임을 실행한다.

## 스크립트가 하는 일

- 게임 폴더 자동 탐지 → SMAPI 최신판 무인 설치 → SAE V2(약 540MB) 내려받아 `Mods`에 설치 → `config.json`에 키·모델 입력 → 바로가기 생성
- 기존 SAE가 있으면 게임 폴더의 `SAE-backup-날짜`로 옮기고 `data`와 `config.json`을 새 버전에 복사
- GMCM(선택)은 넥서스 로그인이 필요해 자동으로 받지 않는다. 다운로드 폴더에 압축 파일이 있으면 함께 설치

## 출처와 확인 상태 (2026-11-21)

- 모드: 디시 스타듀밸리 갤러리 글 279849, 283943, 285961, 키 발급 글 280005
- 받은 파일 해시(SHA256): `ab013b7808eaa6346f1739283ba7ab52c86664de926e35dd970dd57a6a688b28`. 해시가 다르면 스크립트가 묻는다
- 이 스크립트는 리눅스에서 작성했고 **윈도우에서 실제로 실행해 보지 않았다.** 첫 실행에서 오류가 나면 메시지를 그대로 전달할 것
